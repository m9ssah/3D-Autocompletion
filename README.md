# 3D-Autocompletion

## Overview:
Given a partially observed 3D scan (occluded, truncated, or single-view), is it possible to reconstruct the missing geometry, and does a linear or nonlinear latent space recover it better? 

We explore this questione by learning the compressed shape space using PCA and a small autoencoder (CAE), then, use a probability model over that space to fill in the missing geometry. 

In a nutshell, we are attempting to recreate what modern 3D generative AI does, by way of classical ML algorithms.
